# My Launcher

Original minimalist Android launcher prototype. Customizable accent colors, grid size, app labels, searchable app drawer, and swipe-down quick panel.

## APK
GitHub Actions builds a debug APK on every push. Open **Actions → Build Android APK → latest successful run → Artifacts → my-launcher-debug-apk**.

This is an early prototype, not a finished full-featured launcher. Android's system notification shade cannot be replaced by a standard home app.
